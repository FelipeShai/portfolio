Síntese

Este conjunto cobre o fluxo típico de quem administra um sistema Linux pelo terminal: navegar e manipular arquivos → instalar e manter pacotes → inspecionar conteúdo → monitorar processos e serviços → verificar a rede → compactar dados → controlar permissões. Comandos de remoção, permissões e serviços merecem atenção extra: são os que mais causam dor de cabeça quando usados sem cuidado.
